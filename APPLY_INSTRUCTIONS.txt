1DM — Homepage hero: simplified to 2 clips (v4 — IMG_3029 + 1000077708 only)
================================================================================

What changed from the last version
------------------------------------
Simplified down to just the two best-quality clips you pointed to — IMG_3029
(cherries on the branch, tilting up through the canopy) and 1000077708 (the V60
pour-over) — dropping the other four. Both of these were already a clean fit for a
9:16 background with zero cropping or padding needed (one is natively the right
shape, the other just downscales cleanly), which is why they hold up sharper than the
others did.

The two now crossfade into a simple 13.8-second loop: cherries tilting up to the sky
→ pour-over building toward the finished cup, then back to the start. Longer, fuller
takes of each clip than before (7s and 7.6s) so the motion in both reads naturally
rather than feeling cut short.

This drops the roasting, hand-sorting, drying-bed, and espresso shots entirely — say
the word if you'd rather work any of those back in later, now that we know which
clips hold up best at full quality.

What's in this patch
---------------------
- public/videos/hero-bean-to-cup.mp4 (~4.3MB) and hero-bean-to-cup.webm (~4.0MB) —
  much smaller than every previous version, since it's just two clips now.
- public/images/hero/hero-poster.jpg — new poster frame from the pour-over.
- src/app/page.tsx, src/components/hero-video.tsx, src/app/favicon.ico — same as
  before, included again so this zip is a complete drop-in on its own.

Apply it
--------
1. cd ~/Downloads
   rm -rf 1dm-hero-bean-to-cup-v4
   ZIP=$(ls -t 1dm-hero-bean-to-cup-v4*.zip | head -1)
   echo "Using: $ZIP"
   unzip -o "$ZIP" -d 1dm-hero-bean-to-cup-v4

2. cd /home/coffee/Downloads/1dm-website
   cp -r ~/Downloads/1dm-hero-bean-to-cup-v4/. /home/coffee/Downloads/1dm-website/

3. rm -rf .next
   npm run build -- --webpack
   npm run start

4. Check http://localhost:3000 — the hero should loop cherries-on-branch into the
   pour-over and back, sharp with no cropping.

5. git add -A
   git commit -m "Simplify hero video to the two highest-quality clips"
   git push
