1DM — Journal section (brew guides + coffee-origin content)
================================================================

What this is
-------------
A new /journal section, scaffolded from the "content SEO" suggestion you
forwarded (the "build a brew guide" idea). This is a different kind of
thing than the schema/city-page work from last round — that was a one-time
fix, this is infrastructure for an ongoing content habit. It only keeps
paying off if new articles keep getting added over time.

Three articles are live to start, covering exactly the topics you
forwarded:

1. "Dialing In Your V60 (or AeroPress) for Light Roasts"
   Grind/temperature/time adjustments for light roasts specifically, bloom
   technique, inverted AeroPress method, and how to tell if you've under-
   or over-extracted.

2. "Why Degassing Matters Before Your Pour-Over"
   What CO2 does to a fresh bag of beans, why a huge dramatic bloom isn't
   actually a good sign, realistic rest-time windows by roast level, what
   the one-way valve on a bag is for, and how to read your own bloom.

3. "A Field Guide to India's Specialty Coffee Estates"
   The real geography: Chikmagalur, Coorg, Bababudangiris, Wayanad, Araku
   Valley, the Nilgiris — which ones hold GI certification, why India is
   the only country that shade-grows all of its coffee, the S795 varietal
   that makes up a quarter to a third of India's arabica, and Monsooned
   Malabar processing. I fact-checked this one against the Coffee Board of
   India's own regions page, Wikipedia, and the government's GI
   certification announcement before writing it — sources below.

All three end with a soft, non-pushy line connecting back to what's
actually on your bar (rotating single origins, Kruptos roast dates) —
content marketing that funnels toward the cafes without reading like an ad.

How it's built
----------------
Same pattern as the rest of the site: no CMS, no MDX, no new dependencies.
Articles are structured data in src/lib/journal.ts (title, dek, category,
read time, and a body made of paragraph/heading/list/quote blocks),
rendered by src/app/journal/[slug]/page.tsx. Adding a fourth article later
means adding one entry to that file — nothing else changes.

Each article page also carries Article/BlogPosting JSON-LD schema (in
src/lib/schema.ts, tied back to the Organization schema from last round),
and everything is wired into the sitemap, the navbar, and the footer.

Apply it
--------
cd ~/Downloads
rm -rf 1dm-journal
ZIP=$(ls -t 1dm-journal*.zip | head -1)
unzip -o "$ZIP" -d 1dm-journal

cd /home/coffee/Downloads/1dm-website
cp -r ~/Downloads/1dm-journal/. /home/coffee/Downloads/1dm-website/

rm -rf .next
npm run build -- --webpack
npm run start

Check http://localhost:3000/journal and click into each article before
pushing.

git add -A
git commit -m "Add Journal section with 3 brew guide / coffee origin articles"
git push
