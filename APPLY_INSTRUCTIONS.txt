1DM — Fix the browser tab icon (favicon)
=========================================

This is a single-file patch.

What was wrong
---------------
Your site had two different icon files: `src/app/icon.png` (correctly shows the real
"1DM" wordmark — used for things like home-screen/PWA icons) and `src/app/favicon.ico`
(the classic browser-tab icon). The favicon.ico was NOT your logo at all — it was a
generic black circle with a white triangle, unrelated to the brand. Browsers pull
`/favicon.ico` directly for the tab icon, so that's almost certainly what you were
seeing in the tab instead of "1DM".

Fixed by regenerating favicon.ico from the same real "1DM" wordmark used in icon.png,
built as a proper multi-size icon (16/32/48/64/128/256px) so it's crisp in browser tabs,
bookmarks, and anywhere else favicons show up.

Apply it
--------
1. cd ~/Downloads
   rm -rf 1dm-favicon-fix
   unzip -o 1dm-favicon-fix.zip -d 1dm-favicon-fix

2. cd /home/coffee/Downloads/1dm-website
   cp -r ~/Downloads/1dm-favicon-fix/. /home/coffee/Downloads/1dm-website/

3. No dependency or code changes, so skip npm install. Just rebuild:
     rm -rf .next
     npm run build -- --webpack
     npm run start

4. Open http://localhost:3000 in a fresh incognito window (favicons are aggressively
   cached by browsers — a normal tab may keep showing the old one even after this fix).
   You should see "1DM" in the browser tab instead of the black circle/triangle.

5. git add -A
   git commit -m "Fix favicon — was a generic placeholder icon, now the real 1DM wordmark"
   git push

Note: a full wordmark like "1DM" is a little tight at the smallest favicon size (16px)
compared to a single-letter monogram, but it's legible and — most importantly — it's
actually your brand now instead of an unrelated icon. Say the word if you'd rather have
a tighter monogram-style mark designed specifically for the tiny sizes.
